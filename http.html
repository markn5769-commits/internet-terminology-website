Hypertext Transfer Protocol (HTTP)

Definition: HTTP is a protocol used to transfer web pages and data between a web server and a web browser.

How It Works

HTTP works on a request-response model. When you enter a URL in your browser, the browser sends an HTTP request to a web server. The server processes the request and sends back the requested web page as an HTTP response.

Key Features

  • Stateless: Each request is independent
  • Client-Server Model: Communication between browser and server
  • Fast: Designed for quick data transfer

Example

When you type a website address like google.com into your browser, HTTP is used to request the webpage from Google's server and display it on your screen.
