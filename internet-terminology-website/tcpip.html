Transmission Control Protocol / Internet Protocol (TCP/IP)

Definition: TCP/IP is a set of communication protocols used to connect devices over the internet and enable data transmission between them.

How It Works

TCP/IP works by breaking data into small packets before sending them across a network. The Transmission Control Protocol (TCP) ensures that all packets arrive correctly and in order, while the Internet Protocol (IP) is responsible for addressing and routing each packet to the correct destination.

Key Components

  • TCP: Ensures reliable data delivery
  • IP: Handles addressing and routing

Example

When you open a website, your device uses TCP/IP to send a request to the server. The server then sends back the website data in packets, which are reassembled by your device.
