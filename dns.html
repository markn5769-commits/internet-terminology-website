Domain Name System (DNS)

Definition: DNS is a system that translates human-readable domain names into IP addresses that computers use to identify each other on the network.

How It Works

When you type a website address into your browser, DNS servers are used to find the corresponding IP address. The request goes through multiple DNS servers until the correct IP address is found, allowing your browser to connect to the web server.

Key Features

  • Name Resolution: Converts domain names into IP addresses
  • Hierarchical System: Uses multiple levels of servers
  • Fast Lookup: Quickly retrieves stored addresses

Example

When you type "google.com" into your browser, DNS translates it into an IP address like 142.250.190.78 so your device can locate the correct server.
